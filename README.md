## 🌿 What is it?

**SRI Grocery Planner** (Smartlist) is a lightweight web app that turns a grocery shopping list into a neat, shareable **PDF** — no sign-up, no install. Choose what you need, and generate a list or simple bill in one tap.

Built for:
- 🏠 **Families** planning the monthly shopping
- 🏪 **Grocery shops** preparing quick lists and bills

## ✨ Features

| | Feature | What it does |
|---|---|---|
| 🗂️ | **Category filter** | Browse items by category with the *All Categories* dropdown |
| ✅ | **Item selection** | Tap to pick the items you want |
| 🔢 | **Live counter** | *Selected Items* updates as you choose |
| 🧹 | **Clear** | Reset your selection in one tap |
| 📄 | **Generate PDF** | Export your smartlist as a clean, printable PDF |
| 📱 | **Works everywhere** | Phone, tablet or desktop browser |

## 🧭 How to use

1. Open the app → **https://telex2009.github.io/Smartlist/**
2. Choose a category (or keep **All Categories**)
3. Select the items you need and watch **Selected Items** count up
4. Tap **Generate PDF** to download your list
5. Made a mistake? Tap **Clear** and start again
